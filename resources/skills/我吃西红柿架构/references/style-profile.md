# 写作风格参数

把以下内容作为原创中文仙侠和升级流连载小说的默认参数。用户明确提出其他要求时，以用户要求为准。

## 默认参数

| 维度 | 默认设置 | 实际效果 |
|---|---|---|
| 叙事距离 | 贴近人物的第三人称，偶尔拉远 | 主要跟随视角人物的感受和判断；涉及威胁、势力或战场规模时短暂扩大视野。 |
| 节奏 | 快 | 较晚进入场景，从刺激迅速推进到决定；删去不能产生关系变化或实际后果的恢复过程。 |
| 段落密度 | 短 | 一段主要承载一个叙事动作；只有解释规则或综合战术时偶尔使用长段落。 |
| 对白频率 | 中高 | 用对白谈判、试探认知、体现地位并迫使人物作出决定，不重复旁白已经说明的信息。 |
| 感官细节 | 中低 | 选择少量会影响行动的视觉、声音、触觉或身体感受，避免装饰性堆积。 |
| 比喻密度 | 低 | 优先使用直接的物理比较和尺度提示；只在少数敬畏、悲伤或顿悟时刻使用抒情语言。 |
| 情绪直述 | 中低 | 先通过注意力、选择、克制和小动作表现关心、恐惧、决心或悲伤，再考虑是否需要点明。 |
| 信息说明 | 随情境出现、强调实际作用 | 只有规则会改变风险、战术、境界、代价或人物选择时才解释。 |
| 战斗可读性 | 高 | 保持位置、距离、目标、招式、应对、伤害和战术变化清楚。 |
| 章末牵引力 | 中高 | 结束在局势变化或无法回避的下一步上，而不是随意截断。 |

对参考文本的整体统计支持这些倾向：非空段落以短段和中等长度段落为主，对白较多，场景切换通常有明确标记，章节经常在行动、解释、决定和后果之间交替。它们只是倾向，不是硬性配额。

## 叙事推进

多数段落可以围绕一个紧凑的因果单元展开：

`感知或事件 → 当下判断 → 选择 → 可见后果`

压缩例行移动和无效等待。遇到会改变风险、暴露能力、影响关系或产生不可逆代价的选择时，再放慢并展开。一个段落通常承担一种明确功能，不要让描写、历史、情绪和解释在同一段中平均铺开。

优先采用直接的时间推进方式。地点、视角或战略层级改变时，使用清楚的场景分隔。切换后迅速重新交代场景，不重复概述上一段内容。

## 信息说明与成长

把成长写具体，不要只用赞叹宣布升级。突破或新能力应当交代：

- 原先受到的限制；
- 领悟的原理或完成的条件；
- 新增能力产生的可观察效果；
- 仍然存在的限制、代价或不利对局；
- 这次变化为什么会影响接下来的决定。

只有比较能够帮助读者预测结果时，才比较实力。不要反复重述读者已经知道的境界阶梯。引入宏观世界信息时，把它连接到当前场景中的人物、地点、期限、资源或威胁。

允许视角人物分析局势，但分析必须服务于目标。压缩只是重复已知规则的计算。内心推演最后应落到选择、准备或预期变化上。

## 行动与战斗

让对抗在三个层面保持清楚：

1. **物理层面：** 人物在哪里、什么东西移动、什么被击中或避开。
2. **战术层面：** 双方分别想实现什么，哪项判断发生了改变。
3. **后果层面：** 伤势、暴露、资源损失、营救、延误、信息变化或新的力量失衡。

只在碰撞发生的关键时刻选择性使用短句。短句周围仍要有足够的空间和因果信息，不能让速度变成噪声。自然改变句子长度，不要把每个动作句都切成残句。

强敌应当具备能力和计划。胜利应来自准备、判断、牺牲、能力克制、合作或已经获得的成长，不能依赖毫无铺垫的临场压制。

## 人物与关系质感

让主要人物主动行动。场景中的每位重要人物都应有眼前所求，只掌握自己合理获得的信息，并按照自身优先级作出反应。

通过以下因素区分对白：

- 说话直接或委婉的程度；
- 对身份地位的敏感程度；
- 常用词汇；
- 人物刻意回避的内容；
- 人物是正面回答还是转移问题；
- 能表现放松、紧张或习惯的动作节拍。

用具体行为表现关系，例如准备某件东西、察觉疲惫、压下担忧、指出习惯、分享日常、记住实际偏好，或者决定保护谁。行为已经表达出感情、忠诚或悲伤后，不要再反复贴标签说明。

## 自然语言约束

避免让下列通用机器化特征成组出现：

- 相邻段落反复使用同一种过渡句开头；
- 不考虑实际意义，习惯性使用三项并列；
- 一个清楚动作之后，立即解释它代表什么情绪；
- 所有人物的对白都过度完整、过度流畅；
- 形容词只宣布程度，却没有改变读者看到的画面；
- 同一场景中反复提醒境界、目标或人物关系；
- 给普通事件附加空泛的哲理总结；
- 为了显得像真人而故意制造混乱和错误。

修改时保留服务于紧张感、仪式感、人物塑造或信息清晰度的有效重复。不要把所有常用表达都换成华丽近义词。

## 类型调节

用户要求不同子类型时，应调整参数，而不是放弃整个写作方法：

- **冒险：** 增加探索、旅途质感和环境解题。
- **战争：** 更频繁地扩大到战略视角，但要回到个体承受的代价。
- **悬疑：** 降低解释的确定性，记录证据归属，并保证线索公平。
- **感情：** 增加潜台词、关系转折和对细小记忆的关注。
- **暗黑奇幻：** 增强后果与道德压力，但不依赖持续的血腥描写。
- **轻喜剧：** 增强时机错位、意图偏差和人物特有反应，不让每句对白都追求笑点。
