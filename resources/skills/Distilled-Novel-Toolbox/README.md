# 墨脉内置网文 Skill 工具箱

这组 Skill 只保留墨脉原生工作流中有明确职责的模块。目录名是稳定 ID，界面使用中文名称显示。

## 创作 Skill

| 稳定 ID | 中文名称 | 定位 | 主要阶段 |
|---|---|---|---|
| `novel-character-design` | 人物与群像设计 | 人设、关系、动机与成长弧 | 立意、设定 |
| `novel-emotion` | 情绪与代入感 | 情绪曲线、共情和沉浸 | 正文 |
| `novel-innovation` | 创意与反套路 | 差异化与局部创意发散 | 立意、大纲、正文 |
| `novel-language-style` | 语言与文风 | 视角、修辞和画面表达 | 正文 |
| `novel-pacing` | 章节节奏与结构 | 开篇、高潮、断章和章节结构 | 大纲、正文 |
| `novel-pleasure-points` | 爽点设计 | 爽点兑现、密度与疲劳管理 | 大纲、正文 |
| `novel-worldbuilding` | 世界观与设定 | 力量体系、势力和世界规则 | 立意、设定 |

## 分析与审计 Skill

| 稳定 ID | 中文名称 | 定位 | 主要阶段 |
|---|---|---|---|
| `novel-commercialization` | 平台与商业化 | 发布平台、读者与变现判断 | 拆书、立意 |
| `novel-compliance` | 内容合规检查 | 敏感表达与平台审核风险 | 正文审计 |
| `novel-genres` | 题材与类型融合 | 类型惯例和混合题材判断 | 拆书、立意 |

## 使用原则

- 自动模式按任务、阶段和用户提示匹配，不会把整套工具箱全部注入。
- 正文阶段自动最多选择两个 Skill；大纲最多三个；拆书最多一个。
- 同一互斥组只加载一个 Skill，避免两套文风规则互相冲突。
- 项目默认规则在项目设置中管理；单次对话可以临时覆盖。
- 常用组合优先使用界面中的“正文创作、正文润色、大纲设计、设定建设、审计检查”预设。
